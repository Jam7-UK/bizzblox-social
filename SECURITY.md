# Security

Report a vulnerability privately through this repository's
[GitHub security advisory form](https://github.com/Jam7-UK/bizzblox-social/security/advisories/new).
Do not open a public issue containing vulnerability details or customer data.

Reports about unmodified upstream Postiz behaviour may also be reported to the
[Postiz security process](https://github.com/gitroomhq/postiz-app/security/policy).
